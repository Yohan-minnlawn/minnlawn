# Minnlawn Lawn & Landscape

Custom website for Minnlawn Lawn & Landscape in Rochester, Minnesota.

## Project Goals

- Rebuild the existing website with a cleaner, more modern design
- Improve responsiveness across desktop, tablet, and mobile
- Add seasonal service messaging
- Create a photo-focused project gallery
- Improve technical SEO and local Rochester search targeting
- Optimize images and site performance
- Make quote/contact actions easy to access throughout the site

## Planned Features

- Responsive navigation
- Photo-background hero section
- Seasonal service content
- Residential and commercial service sections
- Project gallery
- Customer reviews integrated throughout the site
- Quote/contact form
- SEO metadata and structured data
- Sitemap and robots configuration
- Performance and image optimization

## Hosting

The site is being built as a custom website and will be deployed through Netlify.
